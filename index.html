Chapitre III

Mes Projets

Les réalisations qui ont marqué ma formation

Au cours de mon cursus en BUT Informatique, j'ai eu l'occasion de travailler sur des projets variés, en autonomie et en équipe. Voici les projets les plus significatifs.

SAÉ S5 – Site web de la commune de Beaupont

🏛️ Migration technologique complète

Projet réalisé en équipe de 4 étudiants dans le cadre de la SAÉ du semestre 5. L'objectif : migrer l'intégralité du site web de la commune de Beaupont vers des technologies modernes, tout en conservant les fonctionnalités existantes.

📅 5 mois · 2025 👥 Équipe de 4 📦 CakePHP 5 · Docker · Bootstrap 5
🔍 Zoom technique – Mon rôle
  • Analyse de l'existant : audit du site CakePHP 2 (architecture MVC, base de données, assets)
  • Configuration du nouveau projet CakePHP 5 (config/app.php, connexion BDD, routing)
  • Création des entités ORM conformes à CakePHP 5 avec les conventions de nommage
  • Migration des contrôleurs : adaptation de la logique métier aux nouvelles API du framework
  • Optimisation des requêtes SQL : réécriture avec le QueryBuilder de CakePHP 5
  • Résolution du bug de hashage des mots de passe (incompatibilité Security::hash() → DefaultPasswordHasher)
Compétences mobilisées : C1-Réaliser (AC1 – développer des applications), C2-Optimiser (AC2 – choix algorithmiques), C3-Administrer (AC1 – déploiement Docker), C6-Collaborer (AC1 – travail en équipe)

Stage – API REST au Crédit Agricole Technologies & Services

🏦 API REST pour l'enregistrement des données d'appels téléphoniques

Lors de mon stage au Crédit Agricole Technologies & Services à Annecy, j'ai développé une API REST en Java / Spring Boot 3 pour l'enregistrement des données d'appels téléphoniques, ainsi que la maintenance de scripts Batch.

📅 Avril – Juin 2025 👤 Individuel 📦 Spring Boot 3 · Java · API REST · SQL
🔍 Zoom technique – Détails
  • Conception de l'architecture REST : endpoints CRUD, pagination, filtres de recherche
  • Développement avec Spring Boot : contrôleurs, services, repositories (Spring Data JPA)
  • Modélisation de la base de données et mapping ORM avec JPA/Hibernate
  • Tests unitaires et d'intégration avec JUnit et Mockito
  • Documentation de l'API avec Swagger/OpenAPI
  • Respect des normes de sécurité bancaires et bonnes pratiques de l'entreprise
Compétences mobilisées : C1-Réaliser (AC1 – développer une application), C2-Optimiser (AC3 – qualité de développement), C4-Gérer (AC1 – conception, AC2 – qualité), C5-Conduire (AC1 – besoins du client)

Plateforme de e-santé universitaire

🏥 Conception d'une plateforme de e-santé

Projet de 4 mois en équipe visant à concevoir et développer une plateforme de e-santé universitaire : prise de rendez-vous médicaux, gestion de stocks, et application des normes d'accessibilité.

📅 4 mois · 2024 – 2025 👥 Équipe 📦 CakePHP · Bootstrap · MariaDB
🔍 Zoom technique – Détails
  • Développement Full Stack avec CakePHP et Bootstrap
  • Système de prise de rendez-vous médicaux avec gestion de créneaux
  • Module de gestion de stocks (médicaments, fournitures)
  • Application des normes d'accessibilité (RGAA)

Compétences mobilisées : C1-Réaliser (AC1 – développer des applications), C4-Gérer (AC2 – qualité de développement), C5-Conduire (AC1 – besoins utilisateur), C6-Collaborer (AC1 – travail en équipe)
